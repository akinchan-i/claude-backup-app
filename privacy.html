Privacy policy: Claude backup

Claude backup is a personal tool used only by its owner.

  • It asks Google only for permission to manage the files it creates itself (drive.file). It cannot see any other file in Drive.
  • It uploads the owner's own files to the owner's own Google Drive. Nothing is sent to anyone else.
  • No data is collected, sold or shared, and there are no analytics.
  • Access can be withdrawn at any time at myaccount.google.com → Security → Third-party connections.
